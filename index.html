📅 Smart Church Event Scheduler

A complete web‑based system for churches to manage events, registrations, payments, and member communication.

Built with PHP, MySQL, Bootstrap, and PayPal/MakyPay integration.

▶ Live Demo (PHP Server Required) 📦 GitHub Repository

✨ Key Features

📆 Event Management

Create, edit, approve, and schedule events. Set capacity, date, time, location, and even upload videos or images.

👥 Member & Guest Registration

Members register for events; guests can also sign up with name/email/phone. Admin can approve member accounts.

💳 Online Payments

Accept donations and event fees via PayPal or MakyPay (Mobile Money, Cards). Fully integrated sandbox/live.

📊 Reports & Analytics

Admin dashboard with charts, event reports (CSV/PDF), and real‑time statistics.

🤖 AI Chatbot

Built‑in chatbot on the landing page to answer FAQs about events, registration, and payments.

🔔 Notifications

In‑app notifications for event approvals, registration confirmations, and payment updates.

🚀 Local Setup Instructions

  1. Clone the repository: git clone https://github.com/yourusername/church-scheduler.git
  2. Place the folder in your web server root (e.g., htdocs or www).
  3. Create a MySQL database named church_scheduler and import the SQL schema from config/database.sql.
  4. Update database credentials in config/database.php.
  5. Set your PayPal/MakyPay API keys in config/database.php.
  6. Ensure uploads/ folder is writable.
  7. Access the site at http://localhost/church-scheduler/.
  8. Default admin login: admin / Admin@123.
